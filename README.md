\# CineMatch - AI Movie Recommendation System



\## About

CineMatch is a content-based movie recommendation system that suggests similar movies using genres, keywords, and plot descriptions.



\## Technologies Used

\- Python

\- Pandas

\- Scikit-learn

\- TF-IDF Vectorization

\- Cosine Similarity

\- Streamlit



\## Features

\- Select a movie from the dataset.

\- Get five similar movie recommendations.

\- Explore movie details through an interactive interface.



\## Dataset

TMDB 5000 Movie Dataset.



The credits dataset is uploaded as a ZIP file. Extract `tmdb\_5000\_credits.csv` into the project folder before running the application, unless the code has been updated to read the ZIP directly.



\## How to Run

Install dependencies:



`pip install -r requirements.txt`



Run the application:



`streamlit run app.py`



\## Project Objective

To demonstrate content-based filtering and text similarity for movie recommendations.
